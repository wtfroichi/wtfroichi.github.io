# wtfroichi.github.io
Personal portfolio and project showcase for Roi (wtfroichi).

This repo contains a static site that lists public GitHub projects and presents audiovisual + code work with a hacker/neon aesthetic.

What's included:
- `index.html` — main site (hero, about, projects, contact)
- `assets/styles.css` — neon hacker styles
- `assets/projects.json` — embedded snapshot of public repos (falls back to GitHub API)
- `assets/favicon.svg` — simple neon favicon

To update the embedded projects list automatically, fetch the GitHub API and overwrite `assets/projects.json`.
